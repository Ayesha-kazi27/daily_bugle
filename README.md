# Daily Bugle Tech Expo & Bootcamp UI 🕷️

A responsive, Spider-Man-themed web UI built for the **Daily Bugle Tech Bootcamp**, organized by **GDG (Google Developer Groups)**. 

This project features interactive UI components, dynamic animations

---

## ✨ Features

* **Interactive Stack Carousel:** Smooth drag-and-swipe card stack powered by React and Framer Motion.
* **Scroll-Based Video Scrubbing:** Smooth video animation synced directly with the user's scroll position.
* **Responsive Layout:** Optimized desktop and mobile views with a slide-out navigation menu.
* **Custom Theming:** Spider-Man / Daily Bugle cyber aesthetic, custom glitch headers, and CSS-generated notebook paper textures.

---

## 🛠️ Tech Stack

* **HTML5 & CSS3** (Custom Animations & Layouts)
* **React 18** (UI Logic)
* **Framer Motion** (Drag & Swipe Gestures)
* **Google Fonts** (Orbitron & Courier Prime)

---

## 🚀 Getting Started

1. Clone or download the repository.
2. Ensure assets (`gdg.svg`, `lollll.mp4`, `web_white close.png`) are in the project root folder.
3. Open `index.html` directly in any web browser.
